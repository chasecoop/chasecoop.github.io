I put this up first to prove that a page here can host a live WebGL canvas without slowing the rest
of the site down. It is a wireframe trefoil that turns slowly on its own until you grab it.

Every 3D project follows the same pattern. The scene is a TypeScript module in `src/scripts/three/`
that exports `mount(canvas)` and returns a cleanup function, and Three.js only downloads on pages
that mount one.
