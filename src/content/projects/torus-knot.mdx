This is the template every 3D project on the site follows. The scene is a TypeScript module in
`src/scripts/three/` that exports `mount(canvas)` and returns a cleanup function. The project's
frontmatter names it with `scene:`, and the page loads it on demand, so Three.js only downloads here.

Everything is bundled and served from this domain. No CDN scripts, which keeps the
Content Security Policy strict.
